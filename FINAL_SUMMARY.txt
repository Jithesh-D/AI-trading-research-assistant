🎬 THE USER FLOW
────────────────────────────────────────────────────────────────────────────
1. ASK        → User enters: "Does buying NIFTY after sharp fall work?"
2. CLARIFY    → System shows assumptions (all editable):
                - "Sharp fall" = 2% intraday drop (user can adjust)
                - Entry = Next candle open (user can change)
                - Exit = Same day close (user can refine)
                - Test period = 2 years (user can extend)
                - Costs = 0.1% (user can increase)
3. DEFINE     → Question becomes structured experiment
4. TEST       → Backtest runs on synthetic data (~2 seconds)
5. LEARN      → Results with interpretation:
                - "What the data shows" (factual metrics)
                - "What we believe" (edge exists?)
                - "Important caveats" (sample size, regime, etc.)
